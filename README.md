# Puerto Hype - Mayoreo Streetwear 🇲🇽

Tienda web de comercio electrónico y catálogo mayorista para Puerto Hype.

## 🚀 Características
- **Diseño Cyberpunk / Dark Streetwear:** Paleta de color obsidiana, verde neón (`#CCFF00`), menta (`#00FFA3`) y dorado.
- **Catálogo Interactivo:** Filtros por categoría (Calzado, Hoodies, Pants, Chamarras) y buscador en tiempo real.
- **Carrito Mayorista Inteligente:** Barra de progreso para meta mínima de 6 piezas y cálculo automático de descuentos por volumen.
- **Cotizador WhatsApp:** Genera un pedido con desglose de prendas, tallas y monto listo para enviar al WhatsApp del negocio.
- **100% Responsivo:** Optimizado para dispositivos móviles y adaptable a pantallas de escritorio.

## 🌐 Despliegue en Vercel
Este repositorio está preparado para desplegarse como sitio estático en [Vercel](https://vercel.com) con cero configuración.
